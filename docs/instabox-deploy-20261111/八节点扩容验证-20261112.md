完整维护仍要求每个入口在原端口两次 TCP 均通，并连续通过三轮“实际出口 IP＋真实红包接口”。按实际出口去重，网络失败仅重试一次，风控不重试。正常采集使用五并发、90 毫秒启动间隔、每节点每轮 110 次预算及 180 秒重用间隔。诊断前后也保留 180 秒间隔。

直连 DNS 没有公网 IPv4 答案时，经现有代理交叉查询两处 DoH并保留来源。筛查提示仅在十分钟内、原域名/端口/协议完全匹配且已有两次 TCP 证据时使用，随后仍重新认证。TLS 固定 IP 时保留显式 servername，缺少时补留原域名作为 SNI。

应用配置前保存入口采样、探测时间和冷却记录，避免应用失败后丢失证据。入口和凭据只保存在云机权限 600 的私有文件中。八个选中节点仍共用同一个入口指纹，虽出口不同，入口故障仍会共同影响它们。
