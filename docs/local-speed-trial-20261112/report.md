# 本地速度优化试跑报告

日期：2026-11-12，北京时间。结论：HOT 复查与离线计算耗时改善；实测总查询吞吐没有提高，WARM 复查中位数变慢。应作为调度试验评估，不能宣称整体加速成功。

## 当前实现

- 一次计划中缓存分层与评分，普通冷候选改为有界堆选择，避免对整个大池排序。
- 状态心跳缓存来源成员索引，避免每两秒重新遍历全部房间。
- 无可用出口时跳过计划计算，按最早可用时间唤醒。
- 在节点轮换周期内分散派发，预留 1.8 秒切换余量。
- 本轮内再次到期的 HOT 可以替换普通 COLD 的可调容量；保留普通探索保底、WARM、榜单和历史配额，防止重复排队和同时请求。

保留原有约束：并发 5、启动间隔至少 90 毫秒、节点每轮总预算不超过 110、复用间隔至少 180 秒、风控响应后冷却 15 分钟、保留节点上限 8。没有更换每请求 curl 的传输方式或完整 JSON 原子保存方式。
